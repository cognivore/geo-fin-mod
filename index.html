Financial Model & Simulation Aggregation

We run 10,000 independent simulations of 53 “weeks” (iterations), each starting with initial dimensions [242, 47]. Each iteration calculates cost based on the product of coordinates in all experiments, applies a probabilistic unify or discard step, and records summary statistics.

Cost Formula

In each iteration \(i\), we first compute the total cost as:

\[ \text{Cost}_i \;=\; \frac{\text{cost_per_10000} \times \text{runs_per_iteration} \times \displaystyle\sum_{\exp}\Bigl(\prod_{\text{coord}\in\exp} \text{coord}\Bigr)}{10{,}000}. \]

The constants in this model are:

  • \(\text{cost_per_10000} = 10\,\text{GBP}\), as we will use 50% discount for batch processing in OpenAI API.
  • \(\text{runs_per_iteration} = 7\) we will run seven full scrapes in a week or less.
  • \(\text{reduction_numenator} = 4\) if we are going to unify new dimension with existing ones via dimension elimination, we will strive to eliminate 4/5th of coordinates of interest
  • \(\text{reduction_denominator} = 5\) see above.
  • \(\text{new_dim_size} = 50\) pessimistically, we shall add 50 new coordinates of interest within the new dimension of interest per research sprint.
  • \(\text{unify probability} = 0.9\) we will start tracking a new dimension after we run the research sprint with a 10% probability. Conversely, with a 90% probability, we will absorb the dimension of interest via unification.

Methodology

After the cost is computed, the simulation chooses between unify (90% chance) or discard (10% chance):

  • Unify: Let \(E_1\) be the first experiment. Suppose \(E_1\) has \(n\) coordinates. We create \(n - 1\) new experiments, each one based on \(E_1\) but with one coordinate increased by new_dim_size. The dimensionality (length of each experiment) remains the same, but the number of experiments increases.
  • Discard: For each existing experiment, we scale each coordinate by \(\frac{\text{reduction_denominator}-\text{reduction_numenator}}{\text{reduction_denominator}}\) (never falling below 1), then append a new coordinate of size 50. This increases the dimensionality by 1.

Aggregation

Each simulation records, for every iteration \(i\):

  1. Dimension Count: the dimensionality of experiments (it is an invariant by construction, so we just return dimensionality of \(E_1\)).
  2. Cost Incurred at Given Iteration: \(\text{Cost}_i\) as defined above.
  3. Cumulative Cost: sum of costs up to iteration \(i\).
  4. Average Coordinates: for each coordinate index, we collect all coordinates across all experiments, then compute the mean.

We repeat these 53-week runs 10,000 times and compute an arithmetic average for each metric at each week \(i\). The resulting aggregated data is visualised on this page.
